# Domain Docs

This is a single-context repository.

Before exploring or changing a domain area, read the root `CONTEXT.md` when it
exists and the relevant decisions under `docs/adr/`. If `CONTEXT.md` does not yet
exist, proceed without blocking; it can be created later when domain terminology
needs a dedicated glossary.

Use the domain vocabulary already established by those files. If a proposed change
conflicts with an ADR, surface the conflict explicitly instead of silently
overriding the decision.
